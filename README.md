# Tic-Tac-Toe-Game

Tic Tac Toe game built using programming language/framework used, e.g., JavaScript (React), etc.. Tic Tac Toe is a classic two-player strategy game where players take turns marking a 3x3 grid with their respective symbols (X or O). The first player to align three of their symbols in a row, column, or diagonal wins the game. If the grid is filled without a winner, the game ends in a draw.

Features
✅ Single-player mode (AI opponent)
✅ Two-player mode (local multiplayer)
✅ Interactive UI with real-time updates
✅ Win detection with game-over message
✅ Restart/reset game option
✅ Simple and minimalistic design
